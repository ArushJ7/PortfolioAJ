# Arush Jain — Personal Portfolio

Welcome to my personal portfolio repository. This is a premium, modern, and fully responsive website showcasing my academic journey, B.Tech Computer Science profile, technical skillsets, and development projects.

The application features a sleek dark-themed design system with vibrant gradients, glassmorphism details, glowing backdrops, and fluid micro-animations for an interactive user experience.

## ✨ Features
1. **Premium Modern Aesthetics:** Designed with custom typography (Outfit & Inter), smooth HSL-tailored color gradients, decorative glowing backgrounds, and modern layout conventions.
2. **Dynamic UI Elements:** Custom dark/light theme switcher, animated buttons, project preview cards with interactive hover effects, and a mobile-friendly responsive navigation menu.
3. **Structured Sections:**
   * **Hero Section:** Introducing my role as a CS student and web developer with clear Call-to-Actions (CTAs).
   * **Education & Skills:** A detailed timeline of my B.Tech studies at ADGIPS and interactive cards representing core skills (Programming, Web Dev, DSA, Databases, Tools, and Soft Skills).
   * **Projects Gallery:** Showcasing specific repositories (Guardian AI, BMI Calculator, Password Generator, QR Code Generator) with tag categorizations and direct links to GitHub.
   * **Contact / Connect:** Direct social connection links (GitHub, LinkedIn, Email, Phone, and Location details).

---

## 🛠️ Built With
* **HTML5:** Clean, semantic structure for enhanced SEO accessibility.
* **Vanilla CSS3:** Custom layout styles using Flexbox/Grid, transitions, glassmorphic cards, and custom CSS variables for color scheme themes.
* **JavaScript (ES6+):** Responsive side-navigation menu, theme-switching logic, and interactive components.
* **Lucide Icons:** Modern, clean vector iconography.

## 💻 Getting Started

To run this project locally, follow these simple steps:

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/ArushJ7/PortfolioAJ.git
   ```
2. **Navigate to the Project Folder:**
   ```bash
   cd portfolio
   ```
3. **Open the Project:**
   * Open `index.html` directly in your web browser.
   * Alternatively, use the **Live Server** extension in VS Code or similar web serving tools to host it on `http://localhost`.
